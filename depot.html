📤 Déposer un devoir

Trois étapes : choisissez le devoir, indiquez le lien vers votre travail, et envoyez le message généré à votre enseignant.

Comment ça marche ? Ce site ne stocke pas les fichiers : vous hébergez votre travail sur Google Drive (ou équivalent), puis vous collez le lien de partage ci-dessous. Le bouton « Envoyer » ouvira votre messagerie avec un message déjà rédigé.

1️⃣ Choisissez votre devoir et votre nom

Partagez votre fichier « avec le lien » pour que l'enseignant puisse l'ouvrir.
