📖 Mode d'emploi

La même méthode pour tous les ajouts (devoir, note, dépôt, annonce).

Remplissez le formulaire ci-dessous

Choisissez la section concernée et remplissez les champs.

Cliquez sur « Générer » puis « Copier »

Le site prépare le bloc de code exact à ajouter dans le fichier de données.

Collez-le sur GitHub et enregistrez

Ouvrez le fichier concerné (liens ci-dessous), cliquez sur le crayon ✏️, collez le bloc juste après le crochet ouvrant [, puis cliquez sur « Commit changes ». Le site se met à jour en ~1 minute.

Fichiers : data/devoirs.js · data/notes.js · data/annonces.js · data/eleves.js · data/vie.js

⚙️ Personnalisation

Votre nom, votre e-mail, le titre du site et les classes se modifient dans data/config.js. Les élèves et leurs codes sont dans data/eleves.js. L'emploi du temps, les ressources et les règles sont dans data/vie.js.
